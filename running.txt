أوامر تشغيل وبناء النظام وملف التنصيب (Terminal / PowerShell / CMD):
=============================================================================

1. للتشغيل المباشر للتطوير والتجربة:
   dotnet run --project src/CarRental.App/CarRental.App.csproj
   أو النقر المزدوج على: running.bat

-----------------------------------------------------------------------------
2. بناء ملف التنصيب الذاتي (Installer / Setup) بنقرة واحدة:
   - قم بتشغيل: build_installer.bat
   - سيقوم ببناء التطبيق بالكامل بحزمة ذاتية Self-Contained x64
   - ثم يقوم Inno Setup 7 بتجميع وضغط الملف ليخرج ملف تنصيب احترافي في:
     installer_output\CarRentalSystem_Setup_v1.0.0.exe

-----------------------------------------------------------------------------
3. تصفير قاعدة البيانات لبدء العمل النظيف (بدون سيارات أو عملاء وهميين):
   - قم بتشغيل: reset_database_clean.bat
   - سيقوم بأخذ نسخة احتياطية وتصفير قاعدة البيانات لتكون جاهزة للمكتب فوراً.

-----------------------------------------------------------------------------
4. تخصيص ملف التنصيب والصفحات القانونية:
   - ملف السكريبت: installer\installer.iss
   - الصفحة 1 (شروط الاستخدام والترخيص): installer\license.txt
   - الصفحة 2 (الحقوق والملكية الفكرية): installer\rights.txt
   - الصفحة 3 (طريقة العمل، الدعم الفني، وبيانات المطور): installer\info.txt
