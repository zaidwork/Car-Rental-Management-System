# Car-Rental-Management-System

نظام متكامل وشامل لإدارة وتشغيل مكاتب تأجير السيارات الذكي (WPF .NET 10 + Web Application + Supabase Cloud Sync).

---

## 🌟 نظرة عامة على النظام (Overview)

تم بناء النظام ليوفر حلاً تقنياً عالي الدقة والموثوقية لتشغيل وإدارة أساطيل مكاتب تأجير السيارات، بما يشمل:
- **تطبيق سطح المكتب (Desktop App - WPF / .NET 10)**: نظام سريع، يعمل دون إنترنت (Offline-First 100%)، يدعم الطباعة الفورية لعقود الإيجار، والكمبيالات، وسندات القبض والصرف، وفحص أضرار السيارات التفاعلي.
- **تطبيق الويب (Web Management Dashboard)**: لوحة تحكم سحابية وسريعة لإدارة ومتابعة الأسطول والعقود من أي مكان.
- **المزامنة السحابية (Real-time Cloud Sync)**: مزامنة تلقائية ذكية ثنائية الاتجاه مع قاعدة بيانات سحابية (Supabase) مع الحفاظ على العمل الأوفلاين في حال انقطاع الإنترنت.

---

## 🚀 المميزات الرئيسية (Key Features)

1. **إدارة العقود والعمليات**:
   - فتح عقود محددة المدة أو مفتوحة.
   - حساب دقيق للمدد المنقضية بالساعات والأيام الفعلية.
   - تمديد، استلام، وتسوية العقود مع محرك احتساب الخصومات والتأخير والكيلومتر الزائد.
2. **محاسبة دقيقة وإيرادات الأسطول**:
   - ربط كامل بين العقود وسندات القبض والصرف.
   - حساب ربحية كل مركبة بدقة متناهية وإظهار المستحقات والمدفوعات.
3. **مخطط فحص أضرار السيارات التفاعلي (Vehicle Condition Diagram)**:
   - تحديد نقط الأضرار والخدوش تفاعلياً على مخطط السيارة.
   - مطابقة تامة (Pixel-Perfect) بين الشاشة التفاعلية وطباعة عقود A4 وكشوفات الفحص.
4. **المخطط الزمني والعدادات التنازلية (Live Timeline & Cards)**:
   - متابعة السيارات المؤجرة في الشارع بعدادات تنازلية لحظية بالثواني الحية.
   - التبديل السهل بين عرض البطاقات والمخطط الشريطي (Gantt).
5. **سندات وطباعة متعددة النماذج**:
   - طباعة العقود والكمبيالات الرسمية بقياس A4.
   - طباعة سندات القبض والصرف بقياس A4 وبطابعات الكاشير الحرارية (80mm).

## 🛠️ البنية التقنية (Tech Stack)

- **Desktop**: C# / .NET 10 / WPF / Entity Framework Core / SQLite
- **Web App**: React / Vite / TailwindCSS / Supabase JS Client
- **Installer**: Inno Setup Compiler 7
- **Database**: SQLite (Local Offline) & PostgreSQL (Cloud Supabase)

---

## ⚙️ طريقة التشغيل والإعداد (Setup & Running)

### 1. تطبيق سطح المكتب (.NET Desktop App)
```bash
# استعادة الحزم والبناء
dotnet restore
dotnet build

# التشغيل المباشر
dotnet run --project src/CarRental.App/CarRental.App.csproj
```

### 2. تطبيق الويب (Web App)
```bash
cd "web mange car"
npm install
# قم بنسخ .env.example إلى .env وإضافة مفاتيح سوبابيز الخاصة بك
cp .env.example .env
npm run dev
```
